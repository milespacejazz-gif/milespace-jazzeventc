Milespace｜GitHub Pages 上傳說明

這是 GitHub Pages 專用版本，已將圖片、CSS 與團隊次頁路徑改為相對路徑，支援：
https://你的帳號.github.io/你的儲存庫名稱/

上傳方式：
1. 解壓縮本檔案。
2. 將解壓縮後的「所有內容」放到 GitHub repository 的根目錄。
3. 確認 index.html 直接位於 repository 根目錄，不要多一層 milespace-github-pages 資料夾。
4. GitHub repository 開啟 Settings → Pages。
5. 在 Build and deployment 選 Deploy from a branch，選 main 分支與 /(root)，按 Save。
6. 等待 GitHub Pages 完成部署，再開啟 Pages 顯示的網址。

注意：不能只把 zip 檔上傳到 repository；必須先解壓縮，再上傳裡面的檔案與資料夾。
